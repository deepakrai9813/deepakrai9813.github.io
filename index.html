BIAN AI / Streaming

Show the answer as it arrives.

A tutor’s answer can be several paragraphs long. BIAN reads the response stream a chunk at a time. It holds on to incomplete lines so a network chunk ending halfway through a message can be joined to the next one.

Once a complete event contains text, the client adds it to the reply and calls onDelta. Stop a request early and the student can still read what has arrived. 

const delta = json.choices?.[0]?.delta?.content;
if (typeof delta === "string" && delta) {
  full += delta;
  onDelta?.(delta);
}

Project Sentinel / Recovery

Give recovery a trial run.

Sending every request back to a recovering service can overwhelm it again. Sentinel’s circuit breaker has a half-open state between sending traffic to the backup and fully reopening the primary route.

The default configuration waits five seconds before probing. It allows one trial request at a time and looks for two successes before closing the circuit. 

return Config{
    FailureThreshold:    5,
    SuccessThreshold:    2,
    Timeout:             5 * time.Second,
    MaxHalfOpenRequests: 1,
}

BookHaven / Checkout

Price the order on the server.

A cart can sit open while the catalog changes. At checkout, BookHaven looks up each book again and checks the requested quantity against the available stock.

The order route calculates each line from the catalog price and records the title, price, and quantity on the order. That gives the receipt its own copy of the purchase details.
